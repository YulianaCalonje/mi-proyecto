La ruta POST /reporte permite recibir información enviada por el usuario mediante el cuerpo de la solicitud.
Cuando una persona envía un mensaje, el servidor responde con un objeto JSON indicando que el reporte fue recibido correctamente.
Esta ruta podría servir en una aplicación comunitaria para recibir reportes ciudadanos, alertas, solicitudes de ayuda o información importante enviada por los usuarios.
