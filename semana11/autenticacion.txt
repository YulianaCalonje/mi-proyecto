El login es el proceso mediante el cual un usuario se identifica en una aplicación utilizando sus credenciales. Esto permite verificar su identidad antes de acceder al sistema. Algunas rutas deben estar protegidas porque contienen información privada o funciones que solo pueden usar usuarios autorizados. De esta manera se protege la seguridad de la plataforma. No se deben exponer públicamente contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles de la comunidad.
